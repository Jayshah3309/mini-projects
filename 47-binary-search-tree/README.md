Use the fields and controls shown on the page. Expand Project guide below the demo for the same example and scope notes.

## How it works

Recursive node objects and traversal functions.

Source functions: `insertNode()`, `minNode()`, `deleteNode()`, `searchNodeBST()`, `inorder()`, `preorder()`, `postorder()`, `height()`, `render()`, `insert()`, `removeNode()`, `searchNode()`, `clearTree()`.

## Scope and limitations

Duplicates ignored; skewed trees can have linear height.
